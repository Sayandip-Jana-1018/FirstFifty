description: Kick off a FirstFifty roadmap phase. Expands the phase in docs/ROADMAP.md into an ordered task list in STATUS, checks the prerequisites in docs/SETUP.md, and confirms scope with Sayandip. Use when starting any of Phases 0-5.
argument-hint: "<phase-number>"
---

Starting Phase $ARGUMENTS.

1. Read the phase in `docs/ROADMAP.md`, the docs it references, `docs/RISKS.md`, and the previous phase report.
2. List the prerequisites: accounts, keys and installs from `docs/SETUP.md` needed in this phase; which are done; which Sayandip must do (exact steps, cost, by when).
3. Break the phase into ordered tasks, each small enough for one session. Mark must, should or could; name the agent for each; note dependencies and what can run in parallel (separate worktrees).
4. Write the task list into `docs/STATUS.md` under "Next, in order", with the risks to watch.
5. Show Sayandip a short plan: goal, exit criteria, top tasks, what you need from him, target date. Ask for a go, then start the first task.
